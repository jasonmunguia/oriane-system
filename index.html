Prompt 2 of 3
Filter Recommender
Paste in the same chat after answering Prompt 1. Outputs your exact Oriane search recipe with every filter value.
Using the brand, goal, audience, platform, time period, competitor preferences, creator size, exclusions, and brand voice the user shared earlier in this conversation, output their complete Oriane filter recipe. CONTEXT ON ORIANE FILTERS: Oriane (oriane.xyz) is an AI-powered video intelligence platform that indexes TikTok and Instagram videos and makes them searchable by what actually happens inside each video. It has the following search filters, listed in the exact order they appear in the Oriane interface: 1. AI Vision — computer vision object detection. Input must be 2-3 words maximum — short object labels like "leggings," "gym," "sports bra." Do NOT write long descriptions. Long inputs return zero results because the model detects specific objects, not semantic descriptions. 2. Spoken words — finds videos where specific words are spoken out loud. Has one useful sub-field: └── Contains approximately: brand name or 1-2 key terms only. Do not over-specify — the full audio transcript of every video is included in the CSV export automatically. Over-specifying narrows results to zero. (Do NOT suggest the "Contains all keywords" or "Doesn't contain any keywords" sub-fields for Spoken words — they narrow audio search too aggressively.) 3. Language — spoken language of the video (e.g. English, Spanish). 4. Platforms — TikTok, Instagram, or both. 5. Add date — date range. Calculate the exact start date based on what the user said (e.g. "last 3 months" = today's date minus 3 months). Output as MM/DD/YYYY → Today. 6. Caption — text posted with the video. Has one useful sub-field: └── Contains approximately: brand name or key topic only. (Do NOT suggest "Contains all keywords" or "Doesn't contain any keywords" for Caption — same reason as Spoken words.) 7. Mentions — @handles tagged. All three sub-fields usable: ├── Contains approximately ├── Contains all of these keywords └── Doesn't contain any of these keywords 8. Hashtags — #tags used. Min Engagement — minimum engagement rate threshold. If you got fewer than 25 videos, your filters are too narrow. Here is how each filter works and what to loosen first: - AI Vision detects physical objects on screen (e.g. "handbag", "sneaker", "gym"). It does not understand brand names or long descriptions — keep it to 1-2 concrete object words, or redo it with a simpler object word if results are low. - Spoken words picks up brand names and product terms said out loud in videos (e.g. "Dior", "Nike", "lip gloss"). If you typed more than 1-2 terms, shorten it to just the brand name. Prompt 3 of 3
Director's Creative Brief
Paste in the same chat. Attach your Oriane CSV. Outputs raw HTML — then reply "give me that as a downloadable .html file" and open what the AI sends back. (See Tips below for saving it by hand.)
You are a senior creative strategist, video director, and social media analyst. A CSV file is attached to this message. WHAT IS ORIANE & WHAT THIS CSV CONTAINS: Oriane (oriane.xyz) is an AI-powered video intelligence platform that indexes millions of TikTok and Instagram videos and makes them searchable by what actually happens inside each video — not just the text around it. It analyzes three layers: visual (what appears on screen), audio (what is spoken), and social signals (engagement, creator data). The attached CSV is an export from Oriane. Each row is one video. Key columns include: - Spoken words: THIS IS THE COMPLETE WORD-FOR-WORD AUDIO TRANSCRIPT of everything said in the video. It is NOT a keyword field. Treat it as the full spoken script of the video. This is different from the "Spoken words" search filter used to find videos — the column contains rich, complete transcript data. - Caption / Description: the text the creator posted with the video - Hashtags: tags used in the post - Nb Views, Nb Likes, Nb Comments, Nb Shares, Nb Saves/Favorites: performance metrics - Engagement Rate per Views: engagement rate as a ratio — if all values are below 1, multiply by 100 for display (e.g. 0.067 = 6.7%) - Account Follower Count: creator's follower count at time of posting - Account Username: creator handle - Account Verified: whether the creator is verified - Duration (seconds): video length - Publish Date: when the video was posted - Platform: TikTok or Instagram - Comments: actual comment text if present — use for sentiment analysis If the Spoken words column is missing or empty, fall back to Caption / Description and flag this as a data limitation. YOUR CONTEXT: Read the brand name, goal, target audience, and brand voice/tone shared earlier in this conversation. Adapt every section of the brief to that specific context: - Find winning formats → scripts briefed for internal team or creators to replicate - Creator partnerships → scripts are creator briefs with tier recommendation and outreach angle - Campaign replication → scripts recreate what already performed best - Competitive intelligence → scripts highlight what competitors do that this brand should adopt If no context is found in the conversation, infer everything from the CSV data. BRAND RESEARCH — DO THIS FIRST: 1. Identify the brand from the CSV (scan Spoken words, captions, hashtags) 2. Do ONE web search: "[brand name] brand colors typography visual identity" 3. Extract: primary color, secondary color, accent color, Google Fonts equivalent of their font, visual tone (dark/premium for athletic or luxury, light/clean for wellness, bold/bright for youth or lifestyle) 4. Define all as CSS variables at the top of the HTML 5. Render the brand name as a styled CSS text wordmark in the header — use brand font, weight, letter-spacing, and color. No image fetch. No logo URL. Styled text only. 6. Apply the brand voice/tone from the conversation to all script language, caption copy, and the overall design energy of the HTML. Bold/direct brands get punchy short sentences. Warm/community brands get conversational language. Premium/minimal brands get restrained copy with no exclamation marks. HOW SCRIPTS ARE BUILT — FOLLOW THIS EXACTLY: Each video guide script is engineered by aggregating the best-performing elements across all primary videos in the dataset: - Hook: opening line pattern from the highest-ER video in that format type - Body structure: content sequence and pacing from the highest-view video in that format type - Product placement timing: determined by Section C analysis — use whichever timing bucket (early/mid/late) performs best for the goal (views for viral, ER for conversion) - Language: power words and phrases pulled directly from top-quartile ER transcripts, filtered through the brand voice from the conversation - CTA: type matched to goal — shares CTA for viral, comment CTA for community, save/code CTA for conversion - Duration: optimal word count bucket from Section F analysis The script is never a copy of any one video — it is a new video engineered from what the data proves works across all primary videos. STEP 1 — DATA CLEANING (do this silently, do not narrate): 1. Combine Spoken words + Caption/Description → all_text field 2. Remove all rows with 0 views 3. If all Engagement Rate per Views values are below 1, multiply all by 100 4. Classify each video: PRIMARY (brand mentioned 2+ times in all_text OR is the clear focus of the video) vs INCIDENTAL (mentioned once among many other brands/products) 5. Use PRIMARY videos only for all format detection, hook analysis, and script writing 6. Note the PRIMARY vs INCIDENTAL count — the gap between them is itself an insight about search noise STEP 2 — ANALYSES (run all eight, feed results into HTML): A. WINNING FORMAT MAP Detect video formats from all_text and hashtags — do not assume a fixed list, detect only what actually exists in this dataset. Common signals: unboxing, tutorial, review, before/after, GRWM, day-in-my-life, storytelling, comparison, reaction, talking head, outfit reveal, product drop. For each detected format: video count, avg views, avg ER, avg shares, avg saves, best example (handle + view count). Rank by ER. Flag low video count + high ER as untapped opportunity. B. HOOK ANALYSIS Extract first 1-3 sentences of each Spoken words transcript. Cluster by hook type — detect from data, not from a fixed list. For each type: avg views, avg ER, best example quote. Identify single highest-performing hook pattern by views and describe its structural style (the pattern, not a copy of the exact words). C. PRODUCT PLACEMENT TIMING Where in each transcript is the brand/product first mentioned: early (first 20%), middle (20-60%), late (60%+). Compare avg views and avg ER per bucket. State which performs better for views and which for ER, and by how much. D. LANGUAGE & SENTIMENT PATTERNS Power words in top-quartile ER videos. Positive sentiment signals (obsessed, holy grail, staple, game changer, second skin). Negative signals (disappointed, overrated, returned it). CTA language — correlate each CTA type with: saves (conversion), shares (viral), comments (community). Scan Comments column for recurring themes if present. E. PLATFORM SPLIT If both TikTok and Instagram present: winning format, winning hook type, avg transcript word count, avg ER per platform. If one platform only, note it and continue. F. OPTIMAL DURATION Word count proxy: short = under 75 words (~30s), medium = 75-200 words (30-90s), long = 200+ words (90s+). For each bucket: avg ER, avg views, avg shares, avg saves. State optimal duration for this brand and goal. G. CREATOR TIER PERFORMANCE Nano = under 10K, micro = 10K-100K, mid = 100K-1M, macro = 1M+. For each tier present: avg views, avg ER, avg shares. Flag any smaller creator outperforming larger on ER — high-priority partnership targets. H. POSTING TIME SIGNAL If Publish Date exists: identify days of week and time windows from top-performing videos. Flag any pattern worth replicating. If fewer than 5 data points, state that clearly instead of guessing. STEP 3 — DIRECTOR'S VIDEO GUIDES: Produce one complete video guide per distinct winning format found in Section A. MINIMUM: Always produce at least 3 guides, even if fewer than 3 formats exist. FALLBACK: If fewer than 3 distinct formats detected, produce format variations: Guide 1 = best format viral-optimized (shares), Guide 2 = best format conversion-optimized (saves/comments), Guide 3 = second-best format. Each guide must be fully executable — filmable without a single follow-up question. For each guide output ALL of the following: DATA ANCHOR: specific number from the analysis that justifies this guide GOAL: Viral (share-optimized) or Conversion (save/comment-optimized) PLATFORM: TikTok / Instagram / Both OPTIMAL LENGTH: seconds, from Section F CREATOR TIER: who should make this and why — one specific sentence PRE-PRODUCTION: - Cover frame / thumbnail: single frame that stops the scroll — what is visible, text overlay if any, composition, what is NOT in frame - Talent direction: energy level, pace of speech, eye contact — specific not generic ("speak like you're correcting a friend" not "be authentic") - Location / scene: where to film, what in frame, what not - B-roll to shoot: specific list of supporting shots alongside the main take SCRIPT (word-for-word filmable dialogue — not beat descriptions, actual words): - Hook (land by second 3): exact opening line or visual direction — pull structural pattern from Section B highest-performer - Body: full scripted dialogue with approximate timestamps — language pulled from Section D power words and brand voice - Product moment (at [timestamp]): exact scripted line — timing from Section C, language style from top-performer transcripts - CTA (final [X] seconds): exact scripted line — type matched to goal from Section D VISUAL DIRECTION: - Camera: angle, movement style, distance from subject - Lighting: specific type and quality ("natural window light from the left" not just "natural light") - Product handling: exactly how and when product appears on screen - Aesthetic cues: color palette, texture, vibe — inferred from top-performing video patterns EDITING CUES: - Pacing: cut frequency by section ("cut every 2s during hook, slow to 4-5s during body") - Hook retention: specific direction for first 1-3 seconds - Text overlays: exactly what words, at what moment, in what visual style - Transitions: any specific notes - Music: energy level, BPM range, genre vibe — specific enough to search on TikTok or Epidemic Sound CAPTION COPY: complete caption — hook line, 1-2 body sentences, CTA. Conversational, not corporate. Tone matches brand voice from the conversation. HASHTAG STRATEGY: 5-10 hashtags from top-performing videos in this dataset. Mix broad reach and niche. No generic filler. A/B HOOK ALTERNATIVE: one alternative opening line — different angle, same format and length. POSTING RECOMMENDATION: best day and time from Section H. If data is insufficient, state that clearly. WHY THIS WORKS: 2-3 sentences citing specific numbers — ER figure, view count, share count, or timing finding that makes this guide the right call. STEP 4 — THE GAP INSIGHT: One paragraph only. Single most important finding a brand strategist would want to know — hiding in the data, not surfaceable without analyzing every video. Specific (cite numbers), surprising (not obvious), immediately actionable (tell them what to do about it). HTML OUTPUT REQUIREMENTS: DESIGN: - Single self-contained HTML file — no external dependencies except Google Fonts via link tag - CSS variables for entire color system at top of style block, built from brand research - Brand name as CSS text wordmark in header — brand font, weight, letter-spacing. No images, no external image requests. - Visual tone matches brand: dark/premium for athletic or luxury, light/clean for wellness, bold/bright for lifestyle or youth - Footer: "Powered by Oriane.xyz" with color #CDF460 NAVIGATION: - Sticky tab bar: Overview | Formats | Hooks | Language | Platform & Duration | Creators | Video Guides - Tab switching with CSS fade animation - Active tab has brand accent color underline - Stats bar below header: 6 hero metrics with large numbers JAVASCRIPT: - Stat counters animate from 0 to final value on page load using requestAnimationFrame with easing - Bar charts start at width 0, animate to correct width when their tab becomes active - Video guide cards collapsed by default, click to expand - Hashtag chips hover state transitions to brand accent color COMPONENTS PER TAB: Overview: animated bar chart ranking formats by ER, gap insight as hero callout block Formats: data table with ER color-coded pills (green=high, blue=med, gray=low), untapped flags Hooks: responsive card grid — hook type, large ER number, avg views, best example quote. Hover lifts card. Timing 3-column comparison with winner highlighted and badge. Language: word chips color-coded (power words=brand accent, positive=green, negative=red, CTA=gold). CTA performance table. Platform & Duration: side-by-side platform cards. Duration 3 cards with optimal highlighted. Creators: table with tier color pills, ER color coding, hidden gem flags. Video Guides: collapsed guide cards, click to expand. Script styled as dark terminal with color-coded beat labels: hook=red, body=blue, product moment=green, CTA=gold. Caption in left-border blockquote. Hashtags as hoverable chips. A/B hook in dashed-border box. Why This Works in brand-accent left-border callout. Data constraints grid at bottom. CRITICAL OUTPUT RULE: Output ONLY the raw HTML starting with <!DOCTYPE html>. Nothing before it. Nothing after it. No explanation. No "here is the code." No markdown fences. Just the raw HTML. The user copies it, saves as .html, opens in browser. INSIGHT STANDARD: Every script must be word-for-word filmable by a creator reading it cold. Every data claim must cite a specific number. Every recommendation must pass the so-what test. If data cannot support a claim, say so explicitly.
